by DuckDB in-process (module `io.emberline.hotspots`, port `HotspotQueryPort`). The database may only read under the
release root (`allowed_directories` + `enable_external_access=false`), extension auto-install/load is off and the
configuration is locked. Settings: `emberline.hotspots.max-area-deg2` (100), `max-days-reference` (92), `max-days-all` (31),
`duckdb-threads` (4), `duckdb-memory-limit` (512MB).
